🚀 COMO USAR
────────────────────────────────────────────────────────────────────

INÍCIO RÁPIDO (Windows):
  1. Duplo-clique: iniciar.bat
  2. Aguarde mensagem "SERVIDOR INICIADO!"
  3. Abra navegador: http://localhost:5000

INÍCIO MANUAL:
  1. python install_deps.py
  2. python app.py
  3. Navegador: http://localhost:5000

PARAR:
  - Pressione Ctrl+C no terminal
